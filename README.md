# Unauticna — сайт для GitHub Pages

Статический сайт: HTML, CSS и JavaScript, без сборки и сервера.

## Настройка

Откройте config.js. Укажите почту, телефон, названия проектов и ссылки на страницы Unity Asset Store или файлы для скачивания. Сейчас названия проектов взяты из контекста работы: при необходимости замените их. ФИО также можно изменить.

Изображения положите в assets и укажите, например, image: 'assets/project.png'. Если изображение не задано, карточка показывает инициалы проекта. Чтобы добавить проект или аккаунт, добавьте объект в соответствующий массив.

Политика находится в policy.html: текст приведён из вашего документа с исправлением опечаток.

## GitHub Pages

1. Распакуйте архив и загрузите содержимое unity-assets-site в корень вашего репозитория. index.html должен находиться в корне.
2. В репозитории откройте Settings → Pages.
3. Выберите Deploy from a branch, ветку main и папку / (root), затем Save.
4. Откройте адрес, который покажет GitHub Pages.

Все внутренние пути относительные: сайт подходит и для адреса пользователя, и для сайта отдельного репозитория.

Можно открыть index.html локально. Копирование контактов надёжнее работает по HTTPS на опубликованном сайте.
